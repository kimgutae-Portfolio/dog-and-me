# Moka character sprite

`moka-character-sprite.png` is a 4 × 3 transparent sprite sheet.

Frame order, from left to right:

1. Walk — contact
2. Walk — down
3. Walk — passing
4. Walk — up
5. Idle standing
6. Sitting
7. Sitting with a head tilt
8. Happy / tail wag
9. Speaking — mouth closed
10. Speaking — mouth open
11. Paw wave
12. Resting

Each frame occupies 25% of the image width and 33.333% of the image height.
